# Phase 2

Project Description
This is an interactive web-based quiz application built with **ReactJS**. It is the second phase of the Web Programming project, transitioning from a static site to a dynamic functional application. The app tests users on Computer Science fundamentals (HTML, CSS, SQL, etc.) with real-time scoring.

Features
* **4-Page Navigation**: Includes Home, About, Services, and Contact pages using React Router.
* **Dynamic Quiz Logic**: Integrated quiz system with popup guides and score tracking.
* **Fully Responsive**: Optimized for desktop, tablet, and mobile devices using CSS Flexbox and Media Queries.
* **Modern UI**: Dark theme with professional animations and clear feedback.

Technical Stack
* **Frontend**: ReactJS (Vite)
* **Routing**: React Router DOM
* **Styling**: CSS3 (Responsive Design)
* **Version Control**: Git & GitHub
